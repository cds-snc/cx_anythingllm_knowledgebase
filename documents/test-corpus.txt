SECTION 1: PROJECT OVERVIEW
----------------------------
This repository is configured as a research document corpus using AnythingLLM.
The system uses Retrieval-Augmented Generation (RAG) to answer questions based
solely on uploaded documents. It is configured in Query Mode, which means the
LLM will not use outside knowledge — only content from this corpus.

Key technical facts:
- LLM: Azure OpenAI gpt-4o (CDS Azure endpoint)
- Embedding model: Native (Xenova/all-MiniLM-L6-v2, runs in container)
- Vector database: LanceDB (local)
- Chat mode: Query (document-only, anti-hallucination)

SECTION 2: HOW RAG WORKS
--------------------------
When you ask a question, AnythingLLM does the following:
1. Embeds your question into a vector using the same embedding model.
2. Searches the vector database for the nearest document chunks.
3. Passes those chunks as context to the LLM.
4. The LLM answers using only the provided context.

In Query Mode, if no relevant chunks are found, the system responds:
"I could not find relevant information in your documents."

SECTION 3: CONFIGURATION NOTES
--------------------------------
The similarity threshold controls how strict the search is:
- No restriction: Returns chunks even if loosely related.
- Medium (>= 0.50): Balanced. Recommended starting point.
- High (>= 0.75): Strict. Good for precise factual lookups.

Adjust in workspace Settings > Vector Database Settings.
